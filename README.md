## Cómo integro IA en mi trabajo

Uso IA para explorar soluciones, preparar especificaciones, implementar y revisar código. Aporto el contexto del producto y del repositorio, evalúo las propuestas y compruebo los cambios a lo largo del flujo de trabajo.

- **Definición antes de implementar.** Preciso el problema, las reglas de negocio, los casos límite y los criterios de aceptación.
- **Criterio de arquitectura.** Reviso responsabilidades, contratos tipados y validaciones. Busco reutilizar la lógica existente y reducir duplicación al refactorizar.
- **Comprensión del código.** Analizo cómo se conectan interfaz, API y datos para investigar errores, evaluar alternativas y revisar las propuestas de la IA.
- **Verificación.** Utilizo revisión de cambios, pruebas funcionales y automatizadas, validación de tipos y builds según el alcance del trabajo.
- **Automatización con contexto.** Preparo skills y flujos con MCP para tareas como el refinamiento de cards y la revisión de PRs.
